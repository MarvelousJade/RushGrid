# Worker scaling protocol (defined before execution)

Compare current optimized implementation with zero and five persistent workers at the same source commit. Workload: concourse, 10,000 agents, seed 1337, 60 warm-up ticks and 300 measured ticks, gate closed halfway, detailed profiling off. Five independent captures per condition; alternate pair order: 0/5, 5/0, 0/5, 5/0, 0/5. Measure median run-average tick milliseconds, range, and median within-run p95. Verify identical final state hashes, arrival counts and agent counts across conditions, and run the current regression executable. This measures worker configuration scaling, not an improvement between source revisions. No cold-cache claim, process-memory claim or production capacity claim. Record source hashes, toolchain, hardware, exact commands and every result. Preserve slower results.

Build from current sources with GCC C++20, -O3 -DNDEBUG -Wall -Wextra -Wpedantic and static runtime. Compile the eight library files listed in CMakeLists.txt plus each app/test entry point. Commands and build/test output are recorded in build-and-test.txt; measurement commands and their exit status in commands.json. Do not run timing captures concurrently. Accept a performance claim only if the correctness checks agree; otherwise keep the results with an explanation.
